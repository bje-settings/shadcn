# Generated Components

Everything under `registry/ui/` is generated by `scripts/mirror` from the snapshots in
`upstream/`. Do not edit either by hand: `scripts/mirror/generated.test.ts` fails when a committed
file differs from what the pipeline produces.

- To change a component's output, change the pipeline (`scripts/mirror/`) or `mirror.config.json`,
  then run `pnpm mirror:build`.
- To pick up upstream changes, run `pnpm mirror:fetch` then `pnpm mirror:build`.
- The upstream style and component list live in `mirror.config.json`.
